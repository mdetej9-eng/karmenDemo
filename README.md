# Студия красоты «Кармен» — сайт-визитка

Одностраничный сайт-визитка для студии красоты «Кармен» (г. Ставрополь, пр. Карла Маркса, 42).

## Что внутри

- **Герой-секция** с рейтингом 5.0 из 2ГИС и кнопкой звонка
- **Услуги**: ногти, волосы, косметолог
- **О студии** с фото и преимуществами
- **Галерея работ** с лайтбоксом
- **Контакты**: адрес, телефон, ссылка на карточку 2ГИС

## Технологии

Чистый HTML + CSS + JavaScript, без сборщиков и зависимостей.
Шрифты: Playfair Display + Montserrat (Google Fonts).

## Структура

```
├── index.html      — разметка
├── css/style.css   — стили и адаптив
├── js/main.js      — меню, анимации, лайтбокс
└── img/            — фото работ студии
```

## Запуск

Просто откройте `index.html` в браузере, либо опубликуйте через GitHub Pages.
